# Zapier SDK — Agent Skills

Official agent skills for the [Zapier SDK](https://docs.zapier.com/sdk).

## Install

```bash
npx skills add zapier/sdk
```

Skills are automatically available once installed. Your agent will use them when relevant tasks are detected.

## Available Skills

### zapier-sdk

TypeScript SDK for connecting to 8,000+ apps via Zapier. Handles auth, token refresh, retries, and API differences.

**Use when:**
- Connecting to third-party apps from code
- Running Zapier actions programmatically
- Managing user connections and authenticated API requests
- Working with Zapier Tables
