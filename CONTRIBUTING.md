# Contributing

Thanks for considering a contribution. This repo is the docs and agent skill for [`@zapier/zapier-sdk`](https://www.npmjs.com/package/@zapier/zapier-sdk). The SDK source lives elsewhere — bug reports and feature requests for the SDK itself belong in that repo.

## Before you open anything

1. **Bugs in the SDK itself** — file in the SDK source repo, not here.
2. **Questions** — try [docs.zapier.com/sdk](https://docs.zapier.com/sdk) first.

## CI

Every PR runs [`.github/workflows/validate.yml`](./.github/workflows/validate.yml). See [`.github/scripts/README.md`](./.github/scripts/README.md) for what it checks and how to run the check locally.

## Commit messages

Imperative mood, focused on the *why*. Avoid `update stuff`, `wip`, or commit messages that won't make sense to a reader six months from now.

## Code of conduct

By participating, you agree to abide by the [Code of Conduct](./CODE_OF_CONDUCT.md). Report concerns to **support@zapier.com**.
